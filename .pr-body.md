## What

Bundle of UX improvements after v1.2.1:

### Settings & Vehicles
- Fix endless loader in Settings > Vehicles (no infinite spinner when vehicle box is not open)
- Cached stream for VehicleRepo.watchAll() so vehicles show up immediately after tab switch
- Active vehicle indicator (chip + icon) and "Set Active" action via context menu

### Exports (Ask Where To Save)
- "Ask Where To Save" toggle now respected by:
  - PDF export (Stats)
  - CSV exports (Fuel & Service)
  - Backup export (JSON)
- Fully tested with FakeSaveTargetResolver for ask=true/false and cancel flows

### Vehicle filters (Fuel & Service)
- Added VehicleFilterBar to Fuel and Service tabs
- Three scopes: Active vehicle, All vehicles, Specific vehicle
- Per-tab persistence via UiPrefs
- Localized labels (EN/EL) for:
  - Active vehicle
  - All vehicles
  - All entries

### Stats UI polish
- Prevent clipped "Date" axis in the first panel via padding, minHeight, and better axis config
- Fix overlapping € labels in the second panel (dynamic tick interval, FittedBox, spacing)
- Typography polish: higher-contrast captions and consistent spacing between panels

### Themes
- New AppTheme enum: System, Light, Dark, ComfortLight, Midnight
- Softer default light theme (less blinding)
- ComfortLight and Midnight variants for calmer UIs
- Theme selection dropdown in Settings with immediate apply
- Unit tests for SettingsController theme switching

### Stats metric: L/100km
- Extended StatsMetric with litersPer100km
- UI: added L/100km segmented button with localized label
- Aggregation + chart support for L/100km
- PDF export updated to handle L/100km metric
- Tests covering enum, persistence, UI, and rendering

### Table ↔ Chart interaction
- Tapping a row in the monthly breakdown table highlights the corresponding bar in the chart
- Tapping a bar highlights the corresponding row in the table
- Shared selection state with subtle visual highlighting

### Vehicle UX
- Vehicle list shows active vehicle with chip + icon
- VehicleFormDialog uses a searchable currency picker (same UX as Add Fuel)
- Add Fuel / Add Service forms now include a vehicle selector:
  - Default to active vehicle
  - Save entries with the selected vehicleId
- Tests for currency picker and vehicle selection behavior

## Quality

- flutter analyze: clean (only known deprecation infos)
- flutter test: 160+ tests passing, a few heavy widget tests explicitly skipped by design
- All new features covered with focused unit/widget tests.

## Notes

- This PR is a UX pass on top of v1.2.1, preparing for v1.3.0.
- After manual QA, we can tag v1.3.0 and let the release-on-tag workflow build & upload artifacts (Windows portable ZIP + APK).
